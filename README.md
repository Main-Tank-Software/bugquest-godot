BugQuest SDK for Godot
===========

This is the BugQuest SDK for Godot. BugQuest is a lightweight, comprehensive cloud error and crash monitoring solution for Godot games that is free for most developers.

For more details please see:

[BugQuest Documentation](https://www.bugquest.gg/docs/)
