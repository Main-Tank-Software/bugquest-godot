BugQuest SDK for Godot
===========

This is the BugQuest SDK for Godot. BugQuest is a lightweight, comprehensive cloud error and crash monitoring solution for Godot games that is free for most developers.

For more details please see:

[BugQuest Documentation](https://www.bugquest.gg/docs/)

Build Outputs
- Godot 4.1 compatibility: `BuildsGodot/godot41/addons/gdbq`
- Godot 4.5+: `BuildsGodot/godot45/addons/gdbq_godot45`

Packaging for Release
- Create zip assets containing an `addons/` folder at the root:
  - Godot 4.1 compatibility: zip `BuildsGodot/godot41/addons/gdbq` as `bugquest-godot-4.1.zip`
  - Godot 4.5+: zip `BuildsGodot/godot45/addons/gdbq_godot45` as `bugquest-godot-4.5-plus.zip`
